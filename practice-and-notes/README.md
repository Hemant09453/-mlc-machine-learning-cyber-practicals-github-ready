# Practice and Notes

Supplementary MLC practice work and quick-reference material that is not part
of the ten assessed practicals.

## Contents

| File | Description |
|---|---|
| `mlc_practices_question.ipynb` | NumPy array operations and Matplotlib plotting practice |
| `mlc_practice_question_2.ipynb` | More plotting and Pandas Series/DataFrame practice |
| `dbscan.ipynb` | Minimal DBSCAN example on a toy 2D dataset |
| `dbscan.pdf`, `dbscan.txt` | DBSCAN notes/export |
| `py-basics.pdf` | Python basics reference |
| `quick-reference.txt` | Short command/syntax reference |
| `note.txt` | Miscellaneous notes |

## How to Run

```bash
pip install -r ../requirements.txt
jupyter lab
```

Open any notebook and run the cells. All examples are self-contained and do
not require external datasets.

## Notes

These notebooks are practice material and may contain exploratory or
incomplete code. The assessed practicals are in the sibling
`practical-01-*` to `practical-10-*` folders.
